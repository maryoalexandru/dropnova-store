# DropNova — Demo Dropshipping Storefront

Responsive storefront concept built with HTML, CSS, and vanilla JavaScript for display on GitHub Pages.

## Features
- Eight sample products across Tech, Home, and Lifestyle
- Search, category filters, and sorting
- Demo shopping bag with quantity controls and subtotal
- Responsive desktop and mobile layout
- Newsletter and checkout demo interactions

## Publish on GitHub Pages
1. Create a **new public repository** (keep it separate from any existing site).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` directly to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait a few minutes for the URL to become available.

## Important
This is a visual prototype only. Products, prices, ratings, and images are illustrative. The cart is client-side only; no real orders, email subscriptions, shipping, inventory, or payments are processed. Product photos load from Unsplash and need an internet connection.
